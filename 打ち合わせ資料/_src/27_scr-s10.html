  1. 連携の説明Claude Code が要望を受け取るための端末と鍵を管理する
  2. 端末を通す手元のコマンドで出た合言葉で、Claude Code の端末を通す
  3. 合言葉手元のコマンドで出た8文字を入れる
  4. 合言葉を確かめる合う端末の名前を出し、通すか通さないかを選ばせる
  5. 通した端末通した端末の一覧。いまは無い
  6. 古い方式の鍵古い方式の鍵を発行する区画
  7. 古い方式の注意短い通行証に移す方法と、いま使える鍵の本数（上限10本）
  8. 鍵の使い道どこで使う鍵かを書く。例: 自宅の Claude Code
  9. 鍵を発行する鍵を発行し、一度だけ鍵とコピーのボタンを出す
  10. 発行した鍵発行した鍵の一覧。いまは無い
  11. 設定値の鍵ターミナルから登録した鍵の状態。いまは登録されていない

見本のデータでは出ないもの: 通した端末の行（端末を通すと出る。「この端末を止める」で確認の小窓が出る） / 発行した鍵の行（鍵を発行すると出る。「この鍵を止める」で確認の小窓が出る） / 設定値の鍵を止める（設定値の鍵が登録されているとき、受け取りを止める・再開するボタンが出る） / 鍵が上限10本（使える鍵が10本に達すると、止めてから発行するよう出る）
