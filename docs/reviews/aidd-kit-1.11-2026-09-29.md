## 本質的な課題と対処

キット 1.11.0 の `jp-web-design` は、既存のアプリも平賀配色（明るいほうだけ）へ移すことを既定にしていた。このアプリでそのまま判定すると、置き換え候補が504件の「移行可能」になり、暗い表示と系統の選択・保存が消えるところだった。

| 課題 | 対処 | 置き場所 |
|---|---|---|
| キットの配色の自動移行 | 移さないと決め、T2 と `globals.css` の2か所に宣言した。判定は `report-only` になる | DD-003 / `AGENTS.md` / `scripts/aidd-kit-boundary.test.mjs` |
| 平賀配色を使いたい | 系統 `indigo` として取り込み、既定にした。暗いほうはこのアプリで作った | `docs/product/spec.md`「配色（テーマの系統）」 |
| API と DB で許可値がずれる | 0030 で CHECK に `indigo` を足した | `system-spec/appearance-theme.md` |
| エージェント向けの規約が複数の場所にあった | `AGENTS.md` を正本にし、`CLAUDE.md` はそれを読み込むだけにした | `AGENTS.md` |
| 改善要望の手順と完了の条件 | 手順5に「了承後の続き」と「再開時に渡す情報」を書いた | `.claude/commands/improve-request.md` |
| キット更新時に知らせる内容 | 受け入れ確認9で、キットが古くなくても WARN の一覧は知らせると書いた | `AGENTS.md` |
