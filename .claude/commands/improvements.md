---
description: 利用者から届いている改善要望を一覧で見る（手つかずのものを新しい順に）
---

アプリの利用者が画面から送った改善要望のうち、まだ手をつけていないものを一覧にしてください。

## 手順

1. `pnpm improvements list` を実行する。
2. 通行証が無い旨のメッセージが出た場合は、そのメッセージをそのまま利用者に見せ、
   `pnpm improvements login` を実行してブラウザで承認してもらう手順を案内して終わる。
   承認は人が押すもので、代わりに押せない。勝手に鍵を作らない。
3. 受け取れた場合は、次の形でまとめて提示する。
   - 要望ID / 種類 / どの画面 / 何に困っているかの要約 / いまの状態
   - 同じ画面や同じ困りごとが重なっているものは、まとめて1行で示す
4. 最後に「どれから直しますか」と聞き、
   `/improve-request <要望ID>` で着手できることを伝える。

## 守ること

- 一覧を出すだけで、コードには一切手を入れない。
- 要望の本文には利用者の生の声が入っている。要約するときも意味を変えない。
- 通行証・鍵の値は表示しない。台本も表示しないので、出力をそのまま貼ってよい。
