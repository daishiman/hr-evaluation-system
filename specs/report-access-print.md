# 評価レポートの入口・印刷の差分仕様（2026-10-21）

既存機能の追加改善。正本は[製品仕様 §29](../docs/product/spec.md)、判断は DD-025。Beads `hr-inn.6`、dev-graph `SYS-EVAL-REPORT-P06`。新しい feature/task package は作らない。

| 受入 | 今回の結果として満たす内容 |
|---|---|
| R1 | 全体管理者は会社を選び、その会社の全メンバーのレポートへ社員詳細から直接進める。本人・直属・会社境界・数値非表示は従来どおり |
| R2 | レポートの最新欄は最新確定であると入口に明示する。回答からは回答IDに対応する閲覧可能な評価へ進み、別回答の評価を代用しない |
| R3 | コメントだけの保存では昇給・昇格の可否や設定は変わらないと案内する。点数の判定を覆すには上司の判断と理由を記録して確定する |
| R4 | 専用操作は A3 横（標準1枚）/ A4 縦（初期選択・区切りで複数枚）。A3 は前半とコメントを左・推移と実績を右に並べる。A4 は後半を新しい紙から始め、長文も追加ページで全文を残す。本文へアプリのメニュー・URL を刷らず、ブラウザ固有の余白情報が残るときは設定のオフを案内する。既存の詳細印刷は「評価の詳細を印刷」と区別し、未確定時も維持して同様のURL対策をする。保存・確定などの操作パネルは紙へ出さない |
| R5 | 全紙用グラフとフォントの準備後に印刷を開く。15秒超過時は印刷を開かず理由と再試行を出す。図はベクターのまま使い、A3 の過長は印刷を開かず A4 切替へ案内する。切り詰めや極端な縮小で1枚へ押し込まない |
| R6 | 集計の対象者未指定は全員、空配列は対象なし。直属メンバー0人の上長が他の人の評価・内訳を変更しない |
| R7 | 評価者向けの KPI 一覧はキーごとの獲得点 / 配点・判定を示す。全確定期の等級ラベルと達成率を折れ線・表で比較し、等級を連続数値として扱わない。本人の点数非表示を維持する |
| R8 | 評価詳細の基準帯の黒い縦線は実績値の位置として凡例・単位を示し、獲得点の棒と区別する。範囲外は端に置かれた旨を説明する。現在の設定の帯と保存した判定を混同せず、過去の点数・判定を再計算せず、帯も保存判定で着色しない。集計時の判定を別記する |

スキーマ・数値の単位・所有者・判定方式・公開条件の変更なし。ブラウザ印刷を継続し、サーバーPDF・画像化・全会社一括取得は追加しない。検証・反映状態は[受領書](../docs/product/spec-receipts/2026-10-21-report-access-print.md)。
