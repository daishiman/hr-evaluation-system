# 仕様要約: プロフィール自己編集と利用者管理

> 詳細の正本は `docs/product/spec.md` §3 / §3-1 / §3-2 と `system-spec/account-and-users.md`。

## 利用者から見えること

1. 画面右上の自分のアイコンを押すと、名前・メール・役割・会社の文脈、自分の情報、パスワード、ログアウトが出る
2. 「自分の情報」では氏名・所属・社員番号・入社日・役割・等級・上長・在籍が確認できる
3. 会社が「本人に直してよい」とした項目だけ入力できる。それ以外は鍵付き
4. 会社の管理者は「本人が変更できる項目」画面で 4 項目を切り替えられる
5. システム全体管理者は利用者一覧から誰でも直し、新しいシステム全体管理者も増やせる

## システムが守ること

- 本人が自分を管理者や別等級にできない
- 停止した会社の社員はログインが残っていても中に入れない
- 最後のシステム全体管理者を消して「誰も入れない箱」にしない
- パスワードを管理者が付け直したら、古いログインは切れる
